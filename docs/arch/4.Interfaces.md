# 4. 接口与协议规范

> **注意**：本文档按照优先级组织，外部接口在前，内部接口在后。

## 接口分类

### 内部接口 (Internal APIs)
1. **Session** - 会话管理核心接口
2. **SessionPrompt** - 用户提示处理接口
3. **Tool** - 工具定义和执行接口
4. **Provider** - LLM 提供商管理接口
5. **PermissionNext** - 权限管理接口
6. **Storage** - 本地存储接口
7. **Bus** - 事件总线接口
8. **Instance** - 项目实例管理接口

### 外部接口 (External APIs)
1. **HTTP REST API** - 对外暴露的 RESTful API
2. **OpenCode SDK** - TypeScript/JavaScript 客户端 SDK
3. **SSE Event Stream** - 服务器推送事件流
4. **OpenAPI Specification** - 自动生成的 API 文档

### 进程间接口 (IPC)
1. **WebSocket (PTY)** - 终端实时通信
2. **JSON-RPC (LSP)** - 语言服务器协议
3. **JSON-RPC (MCP)** - 模型上下文协议
4. **Stdio (MCP Local)** - 本地 MCP 服务器通信

## 内部接口详解

### 1. Session 接口

#### 接口定义

```typescript
export namespace Session {
  // 实体类型
  export const Info: z.ZodType<Info>
  export type Info = {
    id: string                    // ses_...
    slug: string                  // 短标识符
    projectID: string             // 项目 ID
    directory: string             // 项目目录
    parentID?: string             // 父会话 ID (fork)
    title: string                 // 会话标题
    version: string               // OpenCode 版本
    time: {
      created: number             // 创建时间 (ms)
      updated: number             // 更新时间 (ms)
      compacting?: number         // 压缩时间
      archived?: number           // 归档时间
    }
    summary?: {                   // 会话摘要
      additions: number           // 新增行数
      deletions: number           // 删除行数
      files: number               // 修改文件数
    }
    share?: {                     // 分享信息
      url: string                 // 分享链接
    }
    permission?: PermissionNext.Ruleset  // 权限规则
    revert?: {                    // 回滚信息
      messageID: string
      partID?: string
      snapshot?: string
      diff?: string
    }
  }

  // 核心方法
  export const create: (input?: {
    parentID?: string
    title?: string
    permission?: PermissionNext.Ruleset
  }) => Promise<Info>

  export const get: (id: string) => Promise<Info>
  export const update: (id: string, fn: (draft: Info) => void) => Promise<Info>
  export const remove: (id: string) => Promise<void>
  export const list: () => AsyncIterable<Info>
  export const messages: (input: { sessionID: string }) => Promise<MessageV2.WithParts[]>

  // 事件
  export const Event = {
    Created: BusEvent<{ info: Info }>
    Updated: BusEvent<{ info: Info }>
    Deleted: BusEvent<{ info: Info }>
    Error: BusEvent<{ sessionID?: string; error: any }>
  }
}
```

**依据**: `packages/opencode/src/session/index.ts:26-488`

---

#### 参数说明

**create(input?)**:
- `parentID`: 父会话 ID (可选)
  - 类型: `string` (ses_...)
  - 必填: 否
  - 用途: 创建子会话 (fork)
- `title`: 会话标题 (可选)
  - 类型: `string`
  - 必填: 否
  - 默认值: `"New session - {ISO8601}"`
- `permission`: 权限规则 (可选)
  - 类型: `PermissionNext.Ruleset`
  - 必填: 否
  - 用途: 预设权限规则

**get(id)**:
- `id`: 会话 ID
  - 类型: `string` (必须以 `ses_` 开头)
  - 必填: 是
  - 验证: `Identifier.schema("session")`

**update(id, fn)**:
- `id`: 会话 ID
  - 类型: `string`
  - 必填: 是
- `fn`: 更新函数
  - 类型: `(draft: Info) => void`
  - 必填: 是
  - 说明: 使用 Immer 草稿模式

---

#### 返回值说明

**create()**:
- 类型: `Promise<Session.Info>`
- 成功: 返回新创建的会话对象
- 失败: 抛出异常

**get()**:
- 类型: `Promise<Session.Info>`
- 成功: 返回会话对象
- 失败: 抛出 `Storage.NotFoundError` (404)

**list()**:
- 类型: `AsyncIterable<Session.Info>`
- 说明: 异步迭代器,按更新时间倒序

---

#### 使用示例

```typescript
// 创建会话
const session = await Session.create({
  title: "Fix authentication bug",
  permission: [
    { permission: "bash", pattern: "npm*", action: "allow" },
    { permission: "edit", pattern: "src/**", action: "allow" }
  ]
})

// 获取会话
const session = await Session.get("ses_01JKL...")

// 更新会话
await Session.update("ses_01JKL...", (draft) => {
  draft.title = "New title"
  draft.time.archived = Date.now()
})

// 列出会话
for await (const session of Session.list()) {
  console.log(session.title)
}

// 订阅事件
Bus.subscribe(Session.Event.Created, (payload) => {
  console.log("Session created:", payload.info.id)
})
```

```typescript
export namespace Tool {
  // 工具上下文
  export type Context<M extends Metadata = Metadata> = {
    sessionID: string

        ctx: Context
      ): Promise<{

        metadata: M
        output: string
        attachments?: MessageV2.FilePart[]
      }>
      formatValidationError?(error: z.ZodError): string
    }>
  }

  // 工具定义辅助函数
  export function define<Parameters extends z.ZodType, Result extends Metadata>(
    id: string,
    init: Info<Parameters, Result>["init"]
  ): Info<Parameters, Result>
}
```

#### 参数说明

**define(id, init)**:
- `id`: 工具唯一标识符
  - 类型: `string`
  - 必填: 是
  - 示例: `"bash"`, `"read"`, `"edit"`
- `init`: 初始化函数

  - 必填: 是
  - 说明: 返回工具描述、参数 Schema 和执行函数

**execute(args, ctx)**:

- `ctx`: 执行上下文
  - 类型: `Tool.Context`
  - 必填: 是
  - 包含: sessionID, messageID, abort, ask, metadata

---

#### 返回值说明

**execute()**:
- 类型: `Promise<{ title, metadata, output, attachments? }>`
- `title`: 工具调用标题 (用于 UI 显示)
- `metadata`: 元数据 (任意 JSON 对象)
- `output`: 工具输出文本 (返回给 LLM)
- `attachments`: 可选的文件附件数组

---

#### 使用示例

```typescript
// 定义工具
export const BashTool = Tool.define("bash", async () => {
  return {
    description: "Execute a bash command",
    parameters: z.object({
      command: z.string(),
      workdir: z.string().optional(),
      description: z.string()
    }),
    async execute(args, ctx) {
      // 请求权限
      await ctx.ask({
        permission: "bash",
        patterns: [args.command],
        always: ["npm*"],
        metadata: {}
      })

      // 执行命令
      const proc = spawn(args.command, { cwd: args.workdir })
      let output = ""
      proc.stdout.on("data", (chunk) => {
        output += chunk.toString()
        // 实时更新元数据
        ctx.metadata({
          metadata: { output: output.slice(0, 30000) }
        })
      })

      await new Promise((resolve) => proc.on("exit", resolve))

      return {
        title: args.description,
        metadata: { output, exit: proc.exitCode },
        output
      }
    }
  }
})
```

### 4. PermissionNext 接口

#### 接口定义

```typescript
export namespace PermissionNext {
  // 权限规则
  export const Rule: z.ZodType<Rule>
  export type Rule = {
    permission: string            // 权限名称 (bash, edit, external_directory)
    pattern: string               // 匹配模式 (支持 wildcard)
    action: "allow" | "deny" | "ask"
  }

  export type Ruleset = Rule[]

  // 权限请求
  export const Request: z.ZodType<Request>
  export type Request = {
    id: string                    // per_...
    sessionID: string
    permission: string
    patterns: string[]            // 要匹配的模式列表
    metadata: Record<string, any>
    always: string[]              // "always allow" 时添加的模式
    tool?: {                      // 关联的工具调用
      messageID: string
      callID: string
    }
  }

  // 权限响应
  export type Reply = "once" | "always" | "reject"

  // 核心方法
  export const ask: (input: Request & { ruleset: Ruleset }) => Promise<void>
  export const reply: (input: {
    requestID: string
    reply: Reply
    message?: string
  }) => Promise<void>
  export const evaluate: (
    permission: string,
    pattern: string,
    ...rulesets: Ruleset[]
  ) => Rule

  // 事件
  export const Event = {
    Asked: BusEvent<Request>
    Replied: BusEvent<{ sessionID: string; requestID: string; reply: Reply }>
  }
}
```

**依据**: `packages/opencode/src/permission/next.ts:12-269`

---

#### 参数说明

**ask(input)**:
- `permission`: 权限名称
  - 类型: `string`
  - 必填: 是
  - 示例: `"bash"`, `"edit"`, `"external_directory"`
- `patterns`: 匹配模式
  - 类型: `string[]`
  - 必填: 是
  - 示例: `["npm test"]`, `["src/auth.ts"]`
- `always`: "always allow" 模式
  - 类型: `string[]`
  - 必填: 是
  - 示例: `["npm*"]`, `["src/**"]`
- `ruleset`: 权限规则集
  - 类型: `Ruleset`
  - 必填: 是
  - 说明: 合并 Agent 和 Session 的规则

**reply(input)**:
- `requestID`: 权限请求 ID
  - 类型: `string` (per_...)
  - 必填: 是
- `reply`: 用户响应
  - 类型: `"once" | "always" | "reject"`
  - 必填: 是
- `message`: 拒绝原因 (可选)
  - 类型: `string`
  - 必填: 否
  - 用途: 提供给 AI 的反馈

---

#### 返回值说明

**ask()**:
- 类型: `Promise<void>`
- 成功: resolve (权限允许)
- 失败: reject with `RejectedError` 或 `DeniedError`

**evaluate()**:
- 类型: `Rule`
- 返回: 匹配的规则或默认规则 `{ action: "ask", permission, pattern: "*" }`

---

#### 使用示例

```typescript
// 请求权限
try {
  await PermissionNext.ask({
    permission: "bash",
    patterns: ["npm test"],
    always: ["npm*"],
    metadata: {},
    sessionID: "ses_01JKL...",
    ruleset: [
      { permission: "bash", pattern: "npm*", action: "allow" },
      { permission: "*", pattern: "*", action: "ask" }
    ]
  })
  // 权限允许,继续执行
} catch (error) {
  if (error instanceof PermissionNext.RejectedError) {
    // 用户拒绝
  } else if (error instanceof PermissionNext.DeniedError) {
    // 规则拒绝
  }
}

// 响应权限请求
await PermissionNext.reply({
  requestID: "per_01JKP...",
  reply: "always"  // 或 "once", "reject"
})

// 评估权限
const rule = PermissionNext.evaluate("bash", "npm test", ruleset)
if (rule.action === "allow") {
  // 允许
}
```

### 2. Server-Sent Events (SSE)

### ID 格式约定

#### 结构

#### 前缀

| 前缀 | 实体类型 |
|------|---------|

#### 排序特性
- **Ascending ID**: 时间戳正序,越新 ID 越大
- **Descending ID**: 时间戳倒序,越新 ID 越小

## 版本兼容性

### 版本管理

- **格式**: `MAJOR.MINOR.PATCH`
