# OpenCode vs KiloCode 快速参考

## 一句话总结

- **KiloCode Task**: VSCode 扩展,简单任务管理,面向结果
- **OpenCode Session**: 独立 CLI/Server,复杂对话管理,面向过程

---

## 核心差异速查表

| 特性 | KiloCode | OpenCode | 推荐 |
|------|----------|----------|------|
| 🎯 核心概念 | Task (任务) | Session (会话) | Session |
| 🌳 分支支持 | ❌ | ✅ Fork | Session |
| 🔐 权限管理 | ❌ | ✅ 细粒度 | Session |
| 📦 上下文压缩 | 手动+自动 | 完全自动 | Session |
| ⭐ 收藏功能 | ✅ | ❌ | Task |
| 📊 排序选项 | ✅ 丰富 | ❌ 单一 | Task |
| 📤 导出功能 | ✅ | ❌ | Task |
| 🗑️ 批量操作 | ✅ | ❌ | Task |
| 🔄 快照回滚 | ❌ | ✅ Git-based | Session |
| 🤖 Agent 系统 | ❌ (仅 Mode) | ✅ 完整 | Session |
| 🎨 Skill 系统 | ❌ | ✅ Markdown | Session |
| 📡 事件系统 | WebSocket | SSE + Bus | Session |
| 🖥️ 终端支持 | VSCode API | PTY + TUI | Session |

---

## 快速决策

### 选择 KiloCode 如果:
```
✅ 必须在 VSCode 中运行
✅ 任务相对独立
✅ 不需要复杂的分支
✅ 重视易用性
✅ 需要任务组织功能
```

### 选择 OpenCode 如果:
```
✅ 需要独立的 CLI/Server
✅ 需要复杂的对话分支
✅ 需要细粒度权限控制
✅ 需要自动上下文管理
✅ 需要高度可扩展性
✅ 需要多 Agent 协作
```

## 核心 API 对比

### 创建会话/任务

**KiloCode**:
```http
POST /tasks
{
  "prompt": "Fix the bug",
  "mode": "code"
}
```

**OpenCode**:
```http
POST /session
{
  "title": "Fix the bug",
  "permission": [...]
}
```

### 发送消息

**KiloCode**:
```http
POST /tasks/{taskId}/messages
{
  "content": "Add tests",
  "images": []
}
```

**OpenCode**:
```http
POST /session/{sessionID}/message
{
  "agent": "build",
  "parts": [
    { "type": "text", "text": "Add tests" }
  ]
}
```

### 上下文压缩

**KiloCode**:
```http
POST /tasks/{taskId}/condense
```

**OpenCode**:
```http
POST /session/{sessionID}/summarize
{
  "providerID": "anthropic",
  "modelID": "claude-sonnet-4",
  "auto": true
}
```

### 分支/Fork

**KiloCode**:
```
❌ 不支持
```

**OpenCode**:
```http
POST /session/{sessionID}/fork
{
  "messageID": "msg_123"
}
```

## 事件订阅

### KiloCode

```javascript
// WebSocket (按 Task 订阅)
const ws = new WebSocket('ws://localhost:3000/api/v1/ws/tasks/task_123')

ws.onmessage = (evt) => {
  const event = JSON.parse(evt.data)
  switch (event.type) {
    case 'task.started':
    case 'task.message':
    case 'task.progress':
    case 'task.completed':
    case 'task.error':
  }
}
```

### OpenCode

```javascript
// SSE (全局订阅)
const eventSource = new EventSource('http://localhost:4096/event')

eventSource.onmessage = (evt) => {
  const event = JSON.parse(evt.data)
  switch (event.type) {
    case 'session.created':
    case 'session.idle':
    case 'message.part.updated':
    case 'permission.asked':
    case 'file.edited':
    // ... 20+ 种事件
  }
}
```

## 权限管理

### KiloCode

```
❌ 无内置权限系统
✅ 依赖 VSCode 沙箱
✅ 工具级别的启用/禁用
```

### OpenCode

```typescript
// 权限规则
{
  "permission": [
    { "permission": "bash", "pattern": "npm*", "action": "allow" },
    { "permission": "bash", "pattern": "rm*", "action": "deny" },
    { "permission": "edit", "pattern": "src/**", "action": "allow" },
    { "permission": "edit", "pattern": ".env", "action": "ask" },
    { "permission": "*", "pattern": "*", "action": "ask" }
  ]
}

// 权限请求流程
1. 工具调用 ctx.ask({ permission: "bash", patterns: ["rm -rf node_modules"] })
2. 评估规则 → action = "deny"
3. 抛出 DeniedError
4. 工具执行中止
```

## Agent 系统

### KiloCode

```typescript
// 简单的 Mode
{
  "mode": "code"      // 编码
  "mode": "architect" // 架构
  "mode": "ask"       // 问答
}
```

### OpenCode

```typescript
// 完整的 Agent 系统
{
  "agent": {
    "build": {
      "permission": { "*": "allow" },
      "prompt": "You are a coding assistant...",
      "model": { "providerID": "anthropic", "modelID": "claude-sonnet-4" }
    },
    "explore": {
      "permission": { "*": "deny", "read": "allow", "grep": "allow" },
      "prompt": "You are a code explorer...",
      "mode": "subagent"
    }
  }
}

// 使用
POST /session/{id}/message
{
  "agent": "explore",  // 切换 Agent
  "parts": [...]
}
```

## 快照与回滚

### KiloCode

```http
# Checkpoint 管理
GET /tasks/{id}/checkpoints
GET /tasks/{id}/checkpoints/{cpId}/diff
POST /tasks/{id}/checkpoints/{cpId}/restore
```

### OpenCode

```http
# Git-based Snapshot
POST /session/{id}/revert
{
  "messageID": "msg_123",
  "partID": "part_456"  # 可选,部分回滚
}

POST /session/{id}/unrevert  # 取消回滚

GET /session/{id}/diff?messageID=msg_123
```

**实现差异**:
- **KiloCode**: 显式的 Checkpoint 管理
- **OpenCode**: 隐式的 Git Snapshot,更轻量

## 性能对比

| 指标 | KiloCode | OpenCode |
|------|----------|----------|
| 启动速度 | 快(VSCode 扩展) | 中(独立进程) |
