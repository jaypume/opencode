## 1. 工具架构对比

### 1.1 OpenCode 工具架构

**核心抽象**:
```typescript
// 文件: opencode/packages/opencode/src/tool/tool.ts:7-88
export namespace Tool {
  export interface Context<M extends Metadata = Metadata> {
    sessionID: string
    messageID: string
    agent: string
    abort: AbortSignal
    callID?: string
    
    // 实时更新元数据
    metadata(input: { title?: string; metadata?: M }): void
    
    // 请求权限
    ask(input: PermissionRequest): Promise<void>
  }
  
  export interface Info<Parameters extends z.ZodType, M extends Metadata> {
    id: string
    init: (ctx?: InitContext) => Promise<{
      description: string
      parameters: Parameters
      execute(args, ctx: Context): Promise<{
        title: string
        metadata: M
        output: string
        attachments?: FilePart[]
      }>
      formatValidationError?(error: z.ZodError): string
    }>
  }
  
  export function define<Parameters, Result>(
    id: string,
    init: Info<Parameters, Result>["init"]
  ): Info<Parameters, Result> {
    return {
      id,
      init: async (initCtx) => {
        const toolInfo = init instanceof Function ? await init(initCtx) : init
        const execute = toolInfo.execute
        
        // 包装 execute,添加参数验证和输出截断
        toolInfo.execute = async (args, ctx) => {
          // 1. 参数验证
          toolInfo.parameters.parse(args)
          
          // 2. 执行工具
          const result = await execute(args, ctx)
          
          // 3. 输出截断
          const truncated = await Truncate.output(result.output, {}, initCtx?.agent)
          
          return {
            ...result,
            output: truncated.content,
            metadata: {
              ...result.metadata,
              truncated: truncated.truncated,
            },
          }
        }
        
        return toolInfo
      },
    }
  }
}
```

**设计特点**:
1. **函数式**: 使用 `Tool.define()` 定义工具
2. **类型安全**: 基于 Zod 的参数验证
3. **上下文传递**: 通过 `Context` 传递会话信息
4. **权限集成**: `ctx.ask()` 请求权限
5. **元数据更新**: `ctx.metadata()` 实时更新
6. **自动截断**: 自动截断过长的输出

### 1.2 KiloCode 工具架构

**核心抽象**:
```typescript
// 文件: kilocode/src/core/tools/BaseTool.ts:44-150
export abstract class BaseTool<TName extends ToolName> {
  abstract readonly name: TName
  
  // 解析 XML/Legacy 参数
  abstract parseLegacy(params: Partial<Record<string, string>>): ToolParams<TName>
  
  // 执行工具
  abstract execute(
    params: ToolParams<TName>,
    task: Task,
    callbacks: ToolCallbacks
  ): Promise<void>
  
  // 处理流式消息
  async handlePartial(task: Task, block: ToolUse<TName>): Promise<void> {
    // 默认实现: 无操作
  }
  
  // 主入口
  async handle(task: Task, block: ToolUse<TName>, callbacks: ToolCallbacks): Promise<void> {
    // 1. 处理流式消息
    if (block.partial) {
      await this.handlePartial(task, block)
      return
    }
    
    // 2. 解析参数
    const params = callbacks.toolProtocol === "native"
      ? block.nativeArgs
      : this.parseLegacy(block.params)
    
    // 3. 执行工具
    await this.execute(params, task, callbacks)
  }
}
```

**设计特点**:
1. **面向对象**: 使用类继承定义工具
2. **协议兼容**: 支持 XML 和 Native 两种协议
3. **流式支持**: `handlePartial()` 处理流式消息
4. **回调模式**: 通过 `ToolCallbacks` 传递功能
5. **任务绑定**: 直接访问 `Task` 实例
6. **手动管理**: 需要手动调用 `pushToolResult()`

### 1.3 架构对比

| 维度 | OpenCode | KiloCode |
|------|----------|----------|
| **定义方式** | 函数式(`Tool.define`) | 面向对象(类继承) |
| **参数验证** | Zod 自动验证 | 手动解析和验证 |
| **协议支持** | 单一协议(AI SDK) | 双协议(XML + Native) |
| **上下文传递** | `Context` 对象 | `Task` + `Callbacks` |
| **权限检查** | `ctx.ask()` | `askApproval()` |
| **元数据更新** | `ctx.metadata()` | `task.say()` |
| **输出截断** | 自动 | 手动 |
| **流式支持** | 通过 `metadata()` | 通过 `handlePartial()` |

### 2.1 文件读取(Read)

#### OpenCode Read Tool

**实现**:
```typescript
// 文件: opencode/packages/opencode/src/tool/read.ts:16-145
export const ReadTool = Tool.define("read", {
  description: DESCRIPTION,
  parameters: z.object({
    filePath: z.string(),
    offset: z.coerce.number().optional(),
    limit: z.coerce.number().optional(),
  }),
  async execute(params, ctx) {
    // 1. 解析路径
    let filepath = params.filePath
    if (!path.isAbsolute(filepath)) {
      filepath = path.join(process.cwd(), filepath)
    }
    
    // 2. 检查外部目录
    await assertExternalDirectory(ctx, filepath)
    
    // 3. 请求权限
    await ctx.ask({
      permission: "read",
      patterns: [filepath],
      always: ["*"],
    })
    
    // 4. 检查文件存在
    const file = Bun.file(filepath)
    if (!(await file.exists())) {
      // 提供文件建议
      const suggestions = fs.readdirSync(dir)
        .filter(entry => entry.toLowerCase().includes(base.toLowerCase()))
        .slice(0, 3)
      throw new Error(`File not found: ${filepath}\n\nDid you mean:\n${suggestions.join("\n")}`)
    }
    
    // 5. 处理图片和 PDF
    const isImage = file.type.startsWith("image/")
    const isPdf = file.type === "application/pdf"
    if (isImage || isPdf) {
      return {
        title,
        output: `${isImage ? "Image" : "PDF"} read successfully`,
        attachments: [{
          type: "file",
          mime: file.type,
          url: `data:${file.type};base64,${Buffer.from(await file.bytes()).toString("base64")}`,
        }],
      }
    }
    
    // 6. 检查二进制文件
    const isBinary = await isBinaryFile(filepath, file)
    if (isBinary) throw new Error(`Cannot read binary file: ${filepath}`)
    
    // 7. 读取文本文件(支持分页)
    const limit = params.limit ?? 2000
    const offset = params.offset || 0
    const lines = await file.text().then(text => text.split("\n"))
    
    // 8. 截断和格式化
    const content = lines
      .slice(offset, offset + limit)
      .map((line, index) => `${(index + offset + 1).toString().padStart(5, "0")}| ${line}`)
      .join("\n")
    
    // 9. 触发 LSP
    LSP.touchFile(filepath, false)
    FileTime.read(ctx.sessionID, filepath)
    
    return {
      title: path.relative(Instance.worktree, filepath),
      output: `<file>\n${content}\n\n(End of file)\n</file>`,
      metadata: { preview, truncated },
    }
  },
})
```

**特点**:
- ✅ 支持图片和 PDF(base64 编码)
- ✅ 智能文件建议(文件不存在时)
- ✅ 二进制文件检测
- ✅ 分页读取(offset + limit)
- ✅ 行号格式化
- ✅ LSP 集成
- ✅ 外部目录保护

```typescript
// 文件: kilocode/src/core/tools/ReadFileTool.ts:109-765
export class ReadFileTool extends BaseTool<"read_file"> {
  async execute(params: { files: FileEntry[] }, task, callbacks): Promise<void> {
    // 1. 参数验证
    if (!params.files || params.files.length === 0) {
      task.consecutiveMistakeCount++
      pushToolResult(await task.sayAndCreateMissingParamError("read_file", "args"))
      return
    }
    
    // 2. 批量处理文件
    const fileResults: FileResult[] = params.files.map(entry => ({
      path: entry.path,
      status: "pending",
      lineRanges: entry.lineRanges,
    }))
    
    // 3. 请求批准(批量)
    for (const fileResult of fileResults) {
      const fullPath = path.resolve(task.cwd, fileResult.path)
      
      // 检查是否在工作区外
      if (isPathOutsideWorkspace(fullPath, task.cwd)) {
        const didApprove = await askApproval("read_file_outside_workspace", fullPath)
        if (!didApprove) {
          updateFileResult(fileResult.path, { status: "denied" })
          continue
        }
      }
      
      filesToApprove.push(fileResult)
    }
    
    // 4. 批量请求批准
    const approvalMessage = formatBatchApprovalMessage(filesToApprove)
    const didApprove = await askApproval("read_file", approvalMessage)
    
    // 5. 读取文件
    for (const fileResult of filesToApprove) {
      try {
        const fullPath = path.resolve(task.cwd, fileResult.path)
        
        // 检查二进制文件
        const isBinary = await isBinaryFile(fullPath)
        
        if (isBinary) {
          // 尝试提取文本(PDF, DOCX 等)
          const supportedFormats = getSupportedBinaryFormats()
          if (supportedFormats.some(fmt => fullPath.endsWith(fmt))) {
            const extractedText = await extractTextFromFile(fullPath)
            updateFileResult(fileResult.path, {
              status: "approved",
              content: extractedText,
            })
            continue
          }
          
          // 处理图片
          if (supportsImages && isSupportedImageFormat(fullPath)) {
            const imageData = await processImageFile(fullPath, imageTracker)
            updateFileResult(fileResult.path, {
              status: "approved",
              imageDataUrl: imageData,
            })
            continue
          }
          
          throw new Error(`Cannot read binary file: ${fullPath}`)
        }
        
        // 读取文本文件
        let content = await fs.readFile(fullPath, "utf-8")
        
        // 6. 处理行范围
        if (fileResult.lineRanges && fileResult.lineRanges.length > 0) {
          content = readLines(content, fileResult.lineRanges)
        }
        
        // 7. Token 预算验证
        const validation = await validateFileTokenBudget(
          content,
          fullPath,
          task.api,
          maxOutputTokens,
        )
        
        if (!validation.withinBudget) {
          // 截断内容
          content = await truncateFileContent(
            content,
            fullPath,
            task.api,
            maxOutputTokens,
          )
        }
        
        // 8. 添加行号
        content = addLineNumbers(content)
        
        // 9. 解析代码定义(可选)
        if (shouldParseDefinitions) {
          const definitions = await parseSourceCodeDefinitionsForFile(fullPath)
          content = definitions + "\n\n" + content
        }
        
        updateFileResult(fileResult.path, {
          status: "approved",
          content,
        })
      } catch (error) {
        updateFileResult(fileResult.path, {
          status: "error",
          error: error.message,
        })
      }
    }
    
    // 10. 格式化输出
    const output = formatFileResults(fileResults, useNative)
    pushToolResult(output)
  }
}
```

**特点**:
- ✅ 批量读取文件
- ✅ 支持行范围(line_range)
- ✅ 图片处理(内存跟踪)
- ✅ 二进制文件提取(PDF, DOCX)

- ✅ 代码定义解析(Tree-sitter)

```typescript
// 文件: opencode/packages/opencode/src/tool/edit.ts:26-145
export const EditTool = Tool.define("edit", {
  parameters: z.object({
    filePath: z.string(),
    oldString: z.string(),
    newString: z.string(),
    replaceAll: z.boolean().optional(),
  }),
  async execute(params, ctx) {
    // 1. 解析路径
    const filePath = path.isAbsolute(params.filePath)
      ? params.filePath
      : path.join(Instance.directory, params.filePath)
    
    // 2. 检查外部目录
    await assertExternalDirectory(ctx, filePath)
    
    // 3. 文件锁
    await FileTime.withLock(filePath, async () => {
      // 4. 处理新文件创建
      if (params.oldString === "") {
        const diff = createTwoFilesPatch(filePath, filePath, "", params.newString)
        
        // 5. 请求权限(带 diff)
        await ctx.ask({
          permission: "edit",
          patterns: [path.relative(Instance.worktree, filePath)],
          metadata: { filepath: filePath, diff },
        })
        
        // 6. 写入文件
        await Bun.write(filePath, params.newString)
        
        // 7. 发布事件
        await Bus.publish(File.Event.Edited, { file: filePath })
        
        // 8. 更新文件时间
        FileTime.read(ctx.sessionID, filePath)
        return
      }
      
      // 9. 读取现有文件
      const file = Bun.file(filePath)
      const stats = await file.stat()
      if (!stats) throw new Error(`File not found: ${filePath}`)
      if (stats.isDirectory()) throw new Error(`Path is a directory: ${filePath}`)
      
      // 10. 检查文件时间(防止并发修改)
      await FileTime.assert(ctx.sessionID, filePath)
      
      // 11. 执行替换
      const contentOld = await file.text()
      const contentNew = replace(contentOld, params.oldString, params.newString, params.replaceAll)
      
      // 12. 生成 diff
      const diff = createTwoFilesPatch(filePath, filePath, contentOld, contentNew)
      
      // 13. 请求权限
      await ctx.ask({
        permission: "edit",
        patterns: [path.relative(Instance.worktree, filePath)],
        metadata: { filepath: filePath, diff },
      })
      
      // 14. 写入文件
      await file.write(contentNew)
      await Bus.publish(File.Event.Edited, { file: filePath })
      
      // 15. 更新元数据(包含 diff 和统计)
      ctx.metadata({
        metadata: {
          diff,
          filediff: {
            file: filePath,
            before: contentOld,
            after: contentNew,
            additions: countAdditions(diff),
            deletions: countDeletions(diff),
          },
        },
      })
      
      // 16. LSP 诊断
      await LSP.touchFile(filePath, true)
      const diagnostics = await LSP.diagnostics()
      const errors = diagnostics[filePath]?.filter(d => d.severity === 1)
      
      if (errors.length > 0) {
        output += `\n\nLSP errors detected:\n${errors.map(LSP.Diagnostic.pretty).join("\n")}`
      }
    })
    
    return { title, output, metadata }
  },
})
```

```typescript
// 文件: opencode/packages/opencode/src/tool/edit.ts:150-646
function replace(content: string, find: string, replace: string, replaceAll?: boolean): string {
  // 1. 规范化换行符
  const normalized = normalizeLineEndings(content)
  const normalizedFind = normalizeLineEndings(find)
  
  // 2. 精确匹配
  if (normalized.includes(normalizedFind)) {
    return replaceAll
      ? normalized.replaceAll(normalizedFind, replace)
      : normalized.replace(normalizedFind, replace)
  }
  
  // 3. 模糊匹配(忽略缩进)
  const candidates = findCandidates(normalized, normalizedFind)
  if (candidates.length === 1) {
    // 单个候选,使用它
    return applyReplacement(normalized, candidates[0], replace)
  }
  
  if (candidates.length > 1) {
    throw new Error(`Multiple matches found. Please provide more context.`)
  }
  
  // 4. 块锚点匹配
  const blockMatches = findBlockAnchors(normalized, normalizedFind)
  if (blockMatches.length === 1) {
    return applyReplacement(normalized, blockMatches[0], replace)
  }
  
  throw new Error(`No match found for oldString`)
}
```

```typescript
// 文件: kilocode/src/core/tools/kilocode/editFileTool.ts:81-300
export async function editFileTool(
  cline: Task,
  block: ToolUse,
  askApproval,
  handleError,
  pushToolResult,
  removeClosingTag,
) {
  const path = block.params.path
  const diff = block.params.diff
  
  try {
    if (block.partial) {
      // 流式显示
      await cline.ask("edit_file", removeClosingTag("path", path), block.partial)
      return
    }
    
    // 1. 参数验证
    if (!path || !diff) {
      cline.consecutiveMistakeCount++
      pushToolResult(await cline.sayAndCreateMissingParamError("edit_file", "path and diff"))
      return
    }
    
    cline.consecutiveMistakeCount = 0
    
    // 2. 请求批准
    const didApprove = await askApproval("edit_file", JSON.stringify({ path, diff }))
    if (!didApprove) return
    
    // 3. 应用 diff
    const result = await applyDiff(path, diff, cline.cwd)
    
    // 4. 推送结果
    if (result.success) {
      pushToolResult(formatResponse.toolResult(`File edited successfully: ${path}`))
    } else {
      pushToolResult(formatResponse.toolError(result.error))
    }
  } catch (error) {
    await handleError("editing file", error)
  }
}
```

```typescript
async function applyDiff(filepath: string, diff: string, cwd: string) {
  const fullPath = path.resolve(cwd, filepath)
  
  // 1. 读取原文件
```

```typescript
            if (!Instance.containsPath(resolved)) {
              directories.add(resolved)
            }

          permission: "external_directory",
          patterns: Array.from(directories),
        })

      if (patterns.size > 0) {
        await ctx.ask({
          permission: "bash",
          patterns: Array.from(patterns),
        })
      }
      
      // 5. 执行命令
      const proc = spawn(params.command, {
        shell,
        cwd,
        env: process.env,
        stdio: ["ignore", "pipe", "pipe"],
        detached: process.platform !== "win32",
      })
      
      let output = ""
      
      // 6. 初始化元数据
      ctx.metadata({
        metadata: {
          output: "",
          description: params.description,
        },
      })
      
      // 7. 流式更新输出
      const append = (chunk: Buffer) => {
        output += chunk.toString()
        ctx.metadata({
          metadata: {
            output: output.slice(0, 30000),  // 截断到 30KB
            description: params.description,
          },
        })
      }
      
      proc.stdout?.on("data", append)
      proc.stderr?.on("data", append)

      const timeoutId = setTimeout(() => {
        timedOut = true
        kill()
      }, timeout)

        aborted = true
        kill()
      })

        proc.on("exit", (code) => {
          exited = true
          clearTimeout(timeoutId)
          resolve(code ?? 0)
        })
      })

      if (timedOut) {
        throw new Error(`Command timed out after ${timeout}ms`)
      }
      
      if (aborted) {
        throw new Error("Command aborted by user")
      }
      
      return {
        title: params.description,
        output: `Exit code: ${exitCode}\n\n${output}`,
        metadata: {
          exitCode,
          output,
          description: params.description,
        },
      }

    }
```

```typescript
      patterns: [params.url],
      metadata: { url: params.url, format: params.format },

    // 4. 构建 Accept header
    let acceptHeader = "*/*"
    switch (params.format) {
      case "markdown":
        acceptHeader = "text/markdown;q=1.0, text/html;q=0.7, */*;q=0.1"
        break
      case "text":
        acceptHeader = "text/plain;q=1.0, text/html;q=0.8, */*;q=0.1"
        break
      case "html":
        acceptHeader = "text/html;q=1.0, */*;q=0.1"
        break
    }
    
    // 5. 发送请求
    const response = await fetch(params.url, {
      signal: AbortSignal.any([controller.signal, ctx.abort]),
      headers: {
        "User-Agent": "Mozilla/5.0 ...",
        "Accept": acceptHeader,
        "Accept-Language": "en-US,en;q=0.9",
      },
    })
    
    clearTimeout(timeoutId)
    
    // 6. 检查响应
    if (!response.ok) {
      throw new Error(`Request failed: ${response.status}`)
    }
    
    // 7. 检查大小
    const contentLength = response.headers.get("content-length")
    if (contentLength && parseInt(contentLength) > 5 * 1024 * 1024) {
      throw new Error("Response too large (exceeds 5MB)")
    }
    
    // 8. 读取内容
    const arrayBuffer = await response.arrayBuffer()
    const content = new TextDecoder().decode(arrayBuffer)
    const contentType = response.headers.get("content-type") || ""
```

```typescript
      text() { /* skip */ }
    })
    .on("*", {
      text(input) {
        text += input.text
      },
    })
    .transform(new Response(html))
```

```typescript
    // 2. 验证工具存在
    const toolValidation = await this.validateToolExists(task, server_name, tool_name, pushToolResult)
    if (!toolValidation.isValid) return
    
    // 3. 请求批准
    const completeMessage = JSON.stringify({
      type: "use_mcp_tool",
      serverName: server_name,
      toolName: tool_name,
      arguments: JSON.stringify(toolArgs),
    })
    
    const executionId = task.lastMessageTs?.toString() ?? Date.now().toString()
    const didApprove = await askApproval("use_mcp_server", completeMessage)
    if (!didApprove) return
    
    // 4. 执行工具
    await this.executeToolAndProcessResult(
      task,
      server_name,
      tool_name,
      toolArgs,
      executionId,
      pushToolResult,
    )
  }
  
  private async executeToolAndProcessResult(...) {
    // 1. 获取 MCP 管理器
    const mcpHub = await task.providerRef.deref()?.getMcpHub()
    if (!mcpHub) {
      throw new Error("MCP Hub not available")
    }
    
    // 2. 更新执行状态
    const status: McpExecutionStatus = {
      executionId,
      status: "running",
      serverName,
      toolName,
    }
    provider.postMessageToWebview({
      type: "mcpExecutionStatus",
      text: JSON.stringify(status),
    })
    
    // 3. 调用 MCP 工具
    const result = await mcpHub.callTool(serverName, toolName, parsedArguments)
    
    // 4. 处理结果
    let output = ""
    for (const content of result.content) {
      if (content.type === "text") {
        output += content.text
      } else if (content.type === "image") {
        output += `[Image: ${content.data}]`
      } else if (content.type === "resource") {
        output += `[Resource: ${content.resource.uri}]`
      }
    }
    
    // 5. 更新状态
    const finalStatus: McpExecutionStatus = {
      executionId,
      status: "completed",
      serverName,
      toolName,
    }
    provider.postMessageToWebview({
      type: "mcpExecutionStatus",
      text: JSON.stringify(finalStatus),
    })
    
    // 6. 推送结果
    pushToolResult(formatResponse.toolResult(output))
  }
}
```

```typescript
    // 1. 创建客户端
    const client = new Client({ name, version: "1.0.0" })

      ? new StdioClientTransport({

    })
```

```typescript
// 文件: opencode/packages/opencode/src/tool/truncation.ts
export namespace Truncate {
  export const MAX_LINES = 1000
  export const MAX_BYTES = 100 * 1024  // 100KB
  
  export async function output(
    content: string,
    metadata: any,
    agent?: Agent.Info
  ): Promise<{ content: string; truncated: boolean; outputPath?: string }> {
    // 1. 检查是否需要截断
    const lines = content.split("\n")
    const bytes = Buffer.byteLength(content, "utf-8")
    
    if (lines.length <= MAX_LINES && bytes <= MAX_BYTES) {
      return { content, truncated: false }
    }
    
    // 2. 截断内容
    const truncated = lines.slice(0, MAX_LINES).join("\n")
    
    // 3. 保存完整输出到文件
    const outputPath = path.join(Truncate.DIR, `${Date.now()}.txt`)
    await Bun.write(outputPath, content)
    
    // 4. 返回截断内容 + 文件路径
    return {
      content: truncated + `\n\n(Output truncated. Full output saved to: ${outputPath})`,
      truncated: true,
      outputPath,
    }
  }
}
```

```typescript
// 文件: kilocode/src/core/tools/helpers/fileTokenBudget.ts
export async function validateFileTokenBudget(
  content: string,
  filepath: string,
  api: ApiHandler,
  maxOutputTokens: number,
): Promise<{ withinBudget: boolean; estimatedTokens: number }> {
  // 1. 估算 Token 数
  const estimatedTokens = await api.countTokens([{ type: "text", text: content }])
  
  // 2. 检查预算
  const withinBudget = estimatedTokens <= maxOutputTokens * 0.8
  
  return { withinBudget, estimatedTokens }
}

export async function truncateFileContent(
  content: string,
  filepath: string,
  api: ApiHandler,
  maxOutputTokens: number,
): Promise<string> {
  const targetTokens = maxOutputTokens * 0.6
  const lines = content.split("\n")
  
  // 二分查找合适的行数
  let left = 0
  let right = lines.length
  let bestLines = 0
  
  while (left <= right) {
    const mid = Math.floor((left + right) / 2)
    const truncated = lines.slice(0, mid).join("\n")
    const tokens = await api.countTokens([{ type: "text", text: truncated }])
    
    if (tokens <= targetTokens) {
      bestLines = mid
      left = mid + 1
    } else {
      right = mid - 1
    }
  }
  
  return lines.slice(0, bestLines).join("\n") + "\n\n(File truncated due to token budget)"
}
```

```typescript
  readonly name = "my_tool" as const
  
  parseLegacy(params): MyToolParams {
    return {
      input: params.input || "",
    }
  }
  
  async execute(params, task, callbacks): Promise<void> {
    const { pushToolResult, askApproval } = callbacks
    
    // 1. 请求批准
    const didApprove = await askApproval("my_tool", params.input)
    if (!didApprove) return
    
    // 2. 执行逻辑
    const result = await doSomething(params.input)
    
    // 3. 推送结果
    pushToolResult(formatResponse.toolResult(result))
  }
}

// 注册工具
// src/core/task/Task.ts
private tools = new Map<ToolName, BaseTool<any>>([
  // ... 其他工具
  ["my_tool", new MyTool()],
])
```

**OpenCode**:
```
声明式 > 命令式
自动化 > 手动控制
权限驱动 > 用户批准
简洁 > 详细
```

**KiloCode**:
```
命令式 > 声明式
手动控制 > 自动化
用户批准 > 权限规则
详细 > 简洁
```

### 12.2 核心差异

| 维度 | OpenCode | KiloCode |
|------|----------|----------|
| **定义方式** | 函数式 | 面向对象 |

| **输出截断** | 自动 | 手动 |
| **LSP 集成** | ✅ | ❌ |
| **事件发布** | ✅ | ❌ |
| **流式更新** | metadata() | handlePartial() |

### 12.3 优势对比

**OpenCode 优势**:
1. ✅ 更简洁的工具定义
2. ✅ 自动化程度高
3. ✅ 细粒度权限控制

5. ✅ LSP 集成
6. ✅ 事件系统集成

**KiloCode 优势**:

## 错误处理对比

### OpenCode (自动包装)

```typescript
// 工具定义
export const MyTool = Tool.define("my-tool", {
  async execute(args, ctx) {
    // 直接抛出错误
    throw new Error("Something went wrong")
  },
})

// 自动包装
toolInfo.execute = async (args, ctx) => {
  try {
    return await execute(args, ctx)
  } catch (error) {
    // 自动格式化错误
    throw new Error(
      `The my-tool tool failed: ${error.message}\n` +
      `Please try again with different parameters.`
    )
  }
}
```

### KiloCode (手动处理)

```typescript
export class MyTool extends BaseTool<"my_tool"> {
  async execute(params, task, callbacks): Promise<void> {
    const { handleError, pushToolResult } = callbacks
    
    try {
      // 执行逻辑
      const result = await doSomething(params)
      
      // 手动推送结果
      pushToolResult(formatResponse.toolResult(result))
    } catch (error) {
      // 手动处理错误
      await handleError("doing something", error)
      
      // 或者推送错误结果
      pushToolResult(formatResponse.toolError(error.message))
    }
  }
}
```

**对比**:
- **OpenCode**: 统一的错误处理
- **KiloCode**: 灵活的错误控制
